## 🌟 Overview

**DevSphere** is a state-of-the-art developer platform and portfolio application built to showcase software engineering projects, data structures & algorithms metrics, and interactive AI capabilities. It combines modern Glassmorphism aesthetics with an active **Google Gemini AI Assistant** integrated into a Node.js/Express backend API.

---

## ✨ Key Features

- 🎨 **Glassmorphism 2.0 Design**: Sleek translucent cards, ambient glowing backdrop orbs, and neon gradient tokens.
- 🌓 **Dynamic Theme Engine**: Persistent Dark and Light theme toggle saved in `localStorage`.
- 🤖 **DevSphere AI Assistant**: Conversational AI assistant powered by Google Gemini API for instant answers regarding skills, experience, and projects.
- 📱 **100% Mobile Responsive**: Floating glass pill navbar with mobile drawer, fluid grid layouts, and zero overflow.
- 📊 **Competitive Programming Metrics**: Visual counters for **600+ DSA problems solved** across LeetCode, Codeforces, and CodeChef.
- 📄 **Resume Download & Preview**: Direct single-click PDF download and inline preview.
- 📬 **Interactive Contact System**: Click-to-copy email/phone buttons with notification toasts and message form.

## 💻 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher)
- npm or yarn

### 1. Clone the Repository
```bash
git clone https://github.com/SANYAM-MANIT/DevSphere.git
cd DevSphere
```

### 2. Backend Setup
```bash
cd Backend
npm install
```

Create a `.env` file inside the `Backend` directory:
```env
PORT=5001
GEMINI_API_KEY=your_google_gemini_api_key_here
```

Start the backend server:
```bash
npm start
```

### 3. Frontend Setup
Open `Frontened/index.html` in your web browser or serve it locally using live server:
```bash
npx -y serve Frontened
```
